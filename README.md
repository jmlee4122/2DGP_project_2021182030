## 🎮 조작키 안내 (Controls)

---

### 시작 화면 (Main Menu)

| 조작키 | 기능 설명 |
| :--- | :--- |
| **Esc** | 게임 종료 |
| **마우스 좌클릭** | 버튼 선택 |

---

### 플레이 화면 (Gameplay)

| 조작키 | 기능 설명 |
| :--- | :--- |
| **←** (왼쪽 방향키) | 플레이어 캐릭터 왼쪽으로 이동 |
| **→** (오른쪽 방향키) | 플레이어 캐릭터 오른쪽으로 이동 |
| **↓** (아래쪽 방향키) | 플레이어 캐릭터 숙이기 |
| **Spacebar** | 플레이어 캐릭터 공격 |
| **Q** | 플레이어 캐릭터 방어 |
| **Esc** | 메뉴 열기 |
